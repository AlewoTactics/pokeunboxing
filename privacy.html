Privacy Policy

Last updated: November 17, 2026

PokeUnboxing Uploader is a personal desktop tool used only by the channel owner.

What data it uses

When the owner authorizes it, the app receives a TikTok access token and basic profile information (open id, display name, avatar) of the owner's own account. It uses them only to upload the owner's videos.

Where data is stored

The token is stored only on the owner's own computer. The app has no server, does not collect data from other people, and does not sell or share any data.

Removing access

Access can be revoked at any time from TikTok: Settings and privacy → Security → Manage app permissions.
